# Slang Reference Notes

The files in this directory are reference material for Slang APIs and language behavior. They are not the Newbie-Renderer shader policy source of truth.

For project shader naming, module layout, runtime binding, and resource-scope rules, follow [../shader/SHADER_NAMING_AND_ORGANIZATION.md](../shader/SHADER_NAMING_AND_ORGANIZATION.md). That guide overrides any general Slang examples here, including examples that place bindable resources on entry-point parameters.
